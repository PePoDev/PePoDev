## Repository Guide

Static GitHub profile with generated activity, blog, and follower sections. `.github/workflows/update-readme.yaml` updates them daily or through `workflow_dispatch`; jobs run sequentially and continue after earlier non-cancellation failures so independent sections still refresh. `.github/workflows/tests.yaml` runs the activity and follower script tests.

Key files: `README.md`, `images/banner.png`, `scripts/updateRecentActivity.js`, and `scripts/getTopFollowers.py`. GitHub Action pins and inline Python dependency pins are reviewed manually.

## Rules

- Keep repository guidance here as the single source of truth.
- Edit only static content outside generated-section markers; workflows overwrite marked content.
- `scripts/getTopFollowers.py` accepts `(github_handle, github_token, readme_path)`.
- Pin Python dependencies inline in workflow install commands; keep shared versions synchronized across workflows. For local setup, use the install command in `.github/workflows/tests.yaml`.
- Run activity tests with `node --test scripts/updateRecentActivity.test.js`.
- Run follower tests with `python -m unittest scripts.test_getTopFollowers`.
- There is no application build or Git hook.
